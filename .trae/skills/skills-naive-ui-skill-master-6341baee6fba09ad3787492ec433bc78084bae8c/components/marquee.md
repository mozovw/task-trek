# 跑马灯 Marquee
我有一个高中同学，当时他的口头禅是：“滚滚滚。”

自 2.40.2 开始提供。


## 演示
在跑马灯中输入文字：

使用 auto-fill 属性让内容铺满空白空间。

你可以将任何内容放入跑马灯中。


## API

### Marquee Props
| 名称 | 类型 | 默认值 | 说明 | 版本 |
| auto-fill | boolean | false | 是否重复的用内容铺满容器的空白 | 2.40.2 |
| speed | number | 48 | 移动的速度，单位是像素每秒 | 2.40.2 |


### Marquee Slots
| 名称 | 参数 | 说明 | 版本 |
| default | () | 内容 | 2.40.2 |
