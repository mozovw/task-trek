# Naive UI 组件库

Naive UI 是一个基于 Vue 3 + TypeScript 的 UI 组件库，提供 90+ 个组件。

## 使用方式

当需要开发 Naive UI 组件时，直接查看对应组件的文档：

```
skills/naive_ui/components/[组件名].md
```

例如：Button 组件文档在 `skills/naive_ui/components/button.md`

## 文档内容

每个组件文档包含：
- **演示**：组件的使用示例和效果说明
- **Props**：所有属性（名称、类型、默认值、说明、版本）
- **Slots**：插槽（名称、参数、说明）
- **Events**：事件（名称、参数、说明）
