# Task-Trek

轻量级任务规划工具，支持三层级任务管理、重复任务系列、打卡系统、进度统计、日历视图、任务倒计时专注模式、白噪音和任务备注。

## 技术栈

| 层 | 技术 |
|---|------|
| 前端 | Vue 3 + Vite + TypeScript + Naive UI + Pinia + Vue Router |
| 后端 | Nest.js + Express + TypeORM + SQLite + JWT |
| 图表 | ECharts |
| 图标 | @vicons/ionicons5 |
| 状态管理 | Pinia (user store, whiteNoise store) |

## 功能

- **三层级任务管理**（一级/二级/三级），树形结构展示，子任务级联创建
- **重复任务系列**：支持按星期频次（周一至周日）配置，自动生成任务副本
- **打卡系统**：打卡/取消打卡，父子任务级联操作
- **倒计时专注模式**：任务计时器每秒同步到数据库，自动打卡完成
- **白噪音播放**：海浪、篝火、雨声、溪水、夜晚、轻松、助眠、钢琴
- **进度统计**：完成概览、完成趋势图（含专注时长）、未完成任务清单
- **日历视图**：展示有耗时的任务，点击日期跳转任务管理
- **Markdown 导入/导出**：支持三级标题、属性字段，重复检测自动覆盖
- **任务备注**：已完成任务可添加/清除备注
- **用户系统**：注册/登录/修改密码，数据按用户隔离
- **薄荷绿主题**：统一的设计语言与配色系统

## 业务规则

### 任务管理
- 新建任务默认一级，通过行内 `+` 按钮创建子任务
- 一级可创建二级，二级可创建三级，三级不可再创建子任务
- 有子任务的父任务预计耗时自动清零
- 统计只计算有预计耗时的叶子节点任务
- 删除任务级联删除所有后代任务及打卡记录
- 任务行缩进：一级 0px，二级 28px，三级 56px
- 已完成任务显示删除线和半透明效果

### 重复任务系列
- 仅一级任务可配置重复，支持选择重复截止日期
- 支持按星期频次（周一至周日复选框）过滤生成日期
- 系统自动从计划日期次日到截止日期生成任务副本（含完整子树）
- 所有副本共享同一 `repeatSeriesId`（UUID），便于批量操作
- 编辑重复系列任务时，名称/描述/预计耗时/层级同步到同系列未完成同级同名任务
- 重复系列任务的计划日期不可修改
- "删除全部"仅删除未完成的重复任务，已完成任务保留
- 序列首尾任务：首/中间任务重复设置置灰，最后一天可重新配置重复

### 打卡与级联
- 打卡/取消打卡在父子任务间级联
- 打卡时所有子任务自动完成，所有同级任务完成时父任务自动完成
- 取消打卡时所有子任务恢复，父任务根据子任务状态自动恢复

### 倒计时专注模式
- 点击计时器按钮开始倒计时（预计耗时 × 60 秒），每秒同步到数据库
- 单个任务运行时锁定其他任务的计时器按钮
- 倒计时归零时自动打卡，播放完成提示音（Web Audio 双音效）
- 编辑进行中的任务会重置计时器状态
- 计时状态刷新页面后自动恢复

### 白噪音
- 支持 9 种音效：无、海浪、篝火、雨声、溪水、夜晚、轻松、助眠、钢琴
- 计时器运行时循环播放，设置按用户持久化
- 浏览器阻止自动播放时，点击页面后自动恢复

### 备注功能
- 仅已完成且有原始预计耗时的任务可添加备注
- 支持保存和清除并保存两种操作

### 日历视图
- 仅展示有预计耗时的任务，已完成任务显示删除线
- 点击日期跳转到任务管理页

### Markdown 导入/导出
- 文件上传模式，接受 `.md` 文件
- 使用 `#` / `##` / `###` 表示三级任务层级
- 支持属性：`日期`、`耗时`、`描述`、`状态`（中英文冒号均可）
- 重复检测：用户 + 父任务 + 名称 + 计划日期 → 自动覆盖

## 数据库

SQLite 文件位于 `backend/data/app.db`，TypeORM 自动建表。

### 数据表

| 表名 | 说明 |
|------|------|
| `users` | 用户信息（含白噪音设置） |
| `tasks` | 任务（三级树形结构，含重复任务系列、倒计时、备注字段） |
| `checkins` | 打卡记录（级联删除） |

### 索引

| 索引名 | 字段 | 说明 |
|--------|------|------|
| `idx_tasks_user_date` | `user_id`, `planned_date` | 按日期查询 |
| `idx_tasks_user_status` | `user_id`, `status` | 按状态筛选 |
| `idx_tasks_user_parent` | `user_id`, `parent_id` | 树形查询 |
| `idx_tasks_repeat_series` | `repeat_series_id` | 重复系列查询 |

### tasks 表关键字段

| 字段 | 说明 |
|------|------|
| `level` | 任务层级：1/2/3 |
| `estimated_minutes` | 预计耗时（分钟），有子任务时自动置 0 |
| `original_estimated_minutes` | 原始预计耗时，用于取消打卡时恢复 |
| `remaining_seconds` | 倒计时剩余秒数 |
| `timer_running` | 计时器运行状态 |
| `repeat_series_id` | 重复任务系列 UUID |
| `repeat_until_date` | 重复截止日期 |
| `repeat_days` | 重复星期频次（JSON 数组，0-6 对应周日-周六） |
| `remark` | 任务备注文本 |
